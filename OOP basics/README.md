# Musical Instrument Class – Python

## Description
A simple Python program demonstrating Object-Oriented Programming (OOP) concepts using a `MusicalInstrument` class. It creates objects representing different musical instruments and displays information about them.

## Concepts Used
- **Classes and Objects:** Creating a `MusicalInstrument` class and its objects.
- **Constructor (`__init__`):** Initializing instrument attributes.
- **Instance Variables:** Storing instrument names and types.
- **Methods:** Defining `play()` and `get_fact()` methods.
- **F-Strings:** Formatting output dynamically.

## Instruments Used
1. **Oboe** – Woodwind family.
2. **Trumpet** – Brass family.

## Sample Output
```text
The Oboe is fun to play!
The Oboe is part of the woodwind family of instruments.
The Trumpet is fun to play!
The Trumpet is part of the brass family of instruments.
```

## How to Run
1. Install Python 3.
2. Save the code as `musical_instrument.py`.
3. Run the following command:

```bash
python musical_instrument.py
```

## Purpose
This project helps beginners understand the fundamentals of Python Object-Oriented Programming through a simple real-world example.
