Tic-Tac-Toe
A simple two-player Tic-Tac-Toe game built using Python. The game runs in the terminal and allows two players to take turns placing `X` and `O` on a 3×3 board.

Features
* Two-player gameplay
* 3×3 game board
* Automatic winner detection
* Draw detection
* Input validation
* Prevents players from selecting an occupied position
* Handles invalid inputs

Concepts Used
* Lists
* Functions
* Loops
* Conditional statements
* Tuples
* List indexing
* `try-except` exception handling
* User input


Enter a number from `1` to `9` to select a position on the board.
text
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9
Players alternate between `X` and `O` until one player wins or the game ends in a draw.
