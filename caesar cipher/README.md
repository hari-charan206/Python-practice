# Caesar Cipher

A simple Python implementation of the Caesar Cipher for encrypting and decrypting text using a specified shift value. 
Each letter is shifted by a fixed number of positions in the alphabet, while spaces, numbers, and special characters remain unchanged. 
The program validates the shift value and supports both uppercase and lowercase letters. 
This project practices Python concepts such as functions, strings, slicing, conditionals, `isinstance()`, `str.maketrans()`, and `str.translate()`. 
This is a learning project and the Caesar Cipher is not suitable for real-world secure encryption.
